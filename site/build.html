Building it

There is no prebuilt binary to download. That's a deliberate consequence of how this project handles game data, not a missing feature — see below. Building it is a handful of commands.

Why there's no download button

This port compiles the extracted game assets directly into the executable rather than reading the ROM at runtime. That means a built binary contains the entire game, not just this project's own code — so a binary isn't this project's to hand out, only yours to build for yourself once you've supplied your own ROM. Full accounting in docs/LICENSING.md.

Nothing in this repository contains game data, and nothing ever will. Not the ROM, not extracted assets, not a texture, not a sound. You supply your own legal copy and the build reads it once, at extraction time.

What you need

Your own legal NTSC (US) GoldenEye 007 cartridge, dumped to a file.

Size12,582,912 bytes exactly
Byte orderBig-endian z64
Header magic80371240
Internal nameGOLDENEYE
SHA-1abe01e4aeb033b6c0836819f549c791b26cfde83

That SHA-1 matches ge007.u.sha1 in the decompilation, so a dump matching it is byte-identical to what a correct US build has to produce. A .n64 or .v64 extension, or a header of 37804012, means byte-swapped — convert to native big-endian first.

Quick start

macOS and Linux:

git clone https://github.com/SegfaultEvan/goldeneye-native.git
cd goldeneye-native
tools/setup.sh                 # fetches deps, applies patches
./getv/build_mac.sh all        # or build_linux.sh
./getv/build-mac/goldeneye --launcher

Windows (PowerShell):

powershell -NoProfile -ExecutionPolicy Bypass -File tools\fetch_deps_windows.ps1
.\getv\build_windows.ps1 -Target all

docs/SETUP.md is the real guide — every prerequisite, every command, the output each should produce, and a troubleshooting section. The asset-generation step is the one you can't shortcut.

Mods and mod packs

There's no separate mod-pack download hub yet — mods live in this repository's own mods/ directory today, and are shared the same way the project itself is: clone it, drop a mod in, or open a pull request. A launcher setting points at whichever mods directory you choose (GETV_MODDIR).

A Lua mod is a mod.lua with any of onFrame, onPlayerSpawn, onWeaponFire, plus a read API into live game state — no rebuild required. The CRT shader (scanlines, aperture mask, barrel curve, vignette) ships as a mod you can read and change. Start at docs/MODDING.md. HD texture replacement is on the roadmap and isn't implemented yet.

Configuration

Most settings live in the launcher. For the rest, one file, written on first run:

Windows%APPDATA%\Goldeneye-Native\
macOS~/Library/Application Support/Goldeneye-Native/
Linux~/.local/share/Goldeneye-Native/

A goldeneye.cfg beside the binary beats it, and --config=<path> / GETV_CONFIG override both. Every key is documented in docs/CONFIGURATION.md.
