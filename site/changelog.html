Changelog

A readable copy of CHANGELOG.md, which is the canonical file. If the two ever disagree, the file in the repository is right.

There are no releases yet. This repository has zero Git tags and zero GitHub Releases as of 2026-09-09. Everything below is unreleased work on main. Do not quote a version number for it — there isn't one. See Releases & versions.

How versions will work

SemVer-style vMAJOR.MINOR.PATCH, which is the shape already written into the project's own RELEASING.md.

The full procedure — version selection, tagging, release notes, snapshot, verification and rollback — is docs/RELEASING.md. No release, tag or GitHub Release may ever carry a ROM, a save, base.zip, extracted game data, a texture dump, an audio bank or a compiled playable binary.

Unreleased

This changelog was started on 2026-09-09, after the work below had already landed. Entries are reconstructed from merged pull requests, which are the reviewable unit here; the commit history before the first pull request is the initial import and is not itemised.

Added

  • Quake-style enemy gibs behind policy gates (#7), and textured blood effects with Base Game controls (#45).
  • In-game developer console: typed core, cross-renderer UI and input capture, a game-thread-owned solo pause policy, read-only session handlers, a runtime gibs command, explicit-slot player mutations and controlled mission transitions (#16, #17, #19, #20, #21, #22, #23, #24).
  • Windows: ROM-free one-click setup and a custom launcher (#54).
  • macOS: application bundles that open the custom launcher (#51) and a saved OpenGL/Metal renderer choice (#67).
  • Metal renderer: three-point texture filtering (#1) and depth-tested blob shadows (#3).
  • Modern mouse look with a classic fallback (e1a52f6).
  • Launcher Developer Tools with local telemetry reports (#58), and versioned PropRecord allocator telemetry (#55).
  • Content-free semantic-row exporter (#29), and standard Claude skill entrypoints with native permission prompts (#56).

Changed

  • Launcher modes clarified; Brutal effects are opt-in and Base Game mission selection is enforced (#66).
  • Mouse input stays active alongside a connected controller instead of being taken away (#57).
  • Explicit save directories are isolated and diagnostic handoffs are retained durably (#59).
  • Transformed asset arrays are generated locally rather than carried in the tree (#28).
  • CI privilege boundary and merge-review baseline hardened (#47, #48); the public-artifact guard now catches generated asset arrays that carry no braces (#60).
  • Contribution evidence tightened: regression tests must actually run in CI (#34), visual fixes need before/after screenshots and skill changes need committed behavioral evals (#65).

Fixed

  • GETV_FILTERING environment precedence (#4) and the file-level widescreen setting (#5).
  • Runway multi-ammo crate halfword order on little-endian hosts (#31).
  • Native collision hull candidates for coincident extrema (#33).
  • Native cuff switch indexing and six-entry bounds (#44).
  • Mouse capture is restored when clicking back into the game after Escape (#50).
  • Fast mouse camera movement with modern mouse look (#64), and auto-crouch across render-only frames (a972003).

Documentation

  • Upstream deletion and maintenance status (#2), community continuation workflow (#6), safe agent contribution workflows (#8), the developer tooling plan (#9), player and contributor guides (#10), and aligned installation walkthroughs (#15).
  • This public site: accurate licensing and provenance language, a documented versioning and archive model, this changelog, and the beginner installation, launcher, settings, FAQ, agent-help, bugs and roadmap pages (milestone 5).
